# 즐거운 카혼수업

카혼의 **이론**, **연주**, **창작**을 배우는 수업용 웹앱입니다. 설치나 빌드 없이 파일만 올리면 동작하는 정적 사이트예요.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 뼈대 |
| `style.css` | 디자인(밝은/어두운 화면 모두 지원) |
| `app.js` | 메뉴, 이론 내용, 연주 리듬, 두드리는 카혼, 창작, 학생 제출, 선생님 화면 |
| `firebase.js` | Firebase 연결(로그인, 저장) |

## 메뉴

- **이론**: 카혼의 유래, 연주 자세, 구조
- **연주**: 기초(기호와 손 표시, 4비트), 기본(8비트, 16비트), 응용(8개 리듬)
- **창작**: 4·8·16비트를 고르고 필인 유무를 정한 뒤 아이콘을 끌어다 놓아 리듬 만들기

모든 화면 오른쪽 위의 `바로가기` 버튼으로 메뉴 트리를 열 수 있어요.

## 기호

| 모양 | 이름 | 설명 |
| --- | --- | --- |
| 빨간 동그라미 | 베이스 (Bass) | 낮은 소리 |
| 파란 네모 | 셰이프 (Shape) | 세게 치기 |
| 노란 다이아몬드 | 터치 (Touch) | 양쪽 가장자리를 약하게 치기 |

기호 안의 `R`은 오른손, `L`은 왼손입니다. 박 세기는 `1 n 2 n 3 n 4 n`이고 n은 박과 박 사이입니다.

## 내 컴퓨터에서 보기

`index.html`을 더블클릭하면 브라우저에서 열려요. 소리가 나려면 화면을 한 번 누르거나 버튼을 눌러야 합니다.

## GitHub에 올리기

### 웹에서 올리기

1. GitHub에서 새 저장소(Repository)를 만듭니다. 이름 예: `cajon-class`
2. 저장소 화면에서 **Add file → Upload files**를 누릅니다.
3. 이 폴더 안의 `index.html`, `style.css`, `app.js`, `firebase.js`, `firestore.rules`, `README.md`를 끌어다 놓고 **Commit changes**를 누릅니다.

### 명령어로 올리기

```bash
cd cajon-class
git init
git add .
git commit -m "즐거운 카혼수업 첫 버전"
git branch -M main
git remote add origin https://github.com/내아이디/cajon-class.git
git push -u origin main
```

### 인터넷 주소 만들기 (GitHub Pages)

1. 저장소의 **Settings → Pages**로 갑니다.
2. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 정하고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://내아이디.github.io/cajon-class/` 주소로 학생들이 접속할 수 있어요.

## 내용 고치기

### 수업 영상 넣기

`app.js` 맨 위쪽의 `VID`에 페이지별 유튜브 영상 ID를 넣으면 그 페이지에 영상이 나옵니다.
영상 주소가 `https://youtu.be/AbCdEfGhIjK`라면 ID는 `AbCdEfGhIjK`입니다.

```js
const VID={o:'AbCdEfGhIjK', po:'', st:'', f1:'', f4:'', m8:'', m16:'', a1:'', ...};
```

| ID | 페이지 |
| --- | --- |
| `o`, `po`, `st` | 이론: 유래, 자세, 구조 |
| `f1`, `f4` | 기초: 기호와 손, 4비트 |
| `m8`, `m16` | 기본: 8비트, 16비트 |
| `a1` ~ `a8` | 응용 1~8 |

### 리듬 바꾸기

`app.js`의 `TREE`에서 각 페이지의 `p:'...'` 문자열이 리듬입니다.

- 칸은 띄어쓰기로 나눕니다.
- 첫 글자는 소리: `B` 베이스, `H` 셰이프, `T` 터치
- 둘째 글자는 손: `R` 오른손, `L` 왼손 (예: `BR`, `HL`, `TL`)
- `.`은 쉼입니다.

```js
{t:'1마디',p:'BR BL HR TL BR BL HR TL'}   // 8비트: 칸이 8개
```

4비트는 4칸, 8비트는 8칸, 16비트는 16칸으로 맞춰 주세요.

### 사진 넣기

이론 페이지의 `사진 자리` 그림 대신 실제 사진을 쓰려면 사진 파일을 같은 폴더에 올리고, `app.js`의 `box(...)` 부분을 `<img src="사진이름.jpg" alt="설명">`으로 바꾸면 됩니다.

## 학생 작품 내기와 선생님 화면 (Firebase)

### 처음 한 번만 준비하기
1. Firebase 콘솔의 Authentication에서 **익명**과 **Google** 로그인을 사용 설정합니다.
2. Authentication → 설정 → 승인된 도메인에 `내아이디.github.io`를 추가합니다.
3. Firestore → 규칙 탭에 `firestore.rules` 내용을 붙여넣고 게시합니다.
4. 배포한 주소 뒤에 `#/teacher`를 붙여 접속해(또는 첫 화면 아래 `선생님 전용`) Google로 로그인합니다.
5. 처음에는 "선생님으로 등록되지 않았어요"와 함께 UID가 나옵니다. Firestore 데이터에서 `teachers` 컬렉션을 만들고 문서 ID에 그 UID를 넣어 저장한 뒤 새로고침합니다.

### 수업할 때
1. 선생님 화면에서 반을 만들고(예: `3-2`) `QR 보기`를 눌러 화면에 띄웁니다.
2. 학생은 QR을 찍고 창작 페이지 맨 아래에서 **개인** 또는 **모둠**을 고르고, 번호(모둠은 모둠 번호 1~30)를 적습니다. `임시 저장`은 선생님에게 아직 보이지 않고, `제출하기`를 누르면 제출됩니다. 제출한 작품은 학생이 고칠 수 없어요.
3. 선생님은 `작품 보기`에서 기본으로 **제출한 작품**만 보고, `작성 중 포함 전체`로 바꾸면 임시 저장도 볼 수 있습니다. 모둠 작품과 개인 작품이 나뉘어 나오고, 들어 보기와 삭제를 할 수 있습니다. 학생이 고쳐야 할 때는 `제출 풀기`를 누릅니다.
4. `작품 보기` 맨 위의 **제출 현황**에서 번호별 제출(✓), 작성 중(●), 아직 안 냄(○)과 아직 안 낸 번호를 한눈에 봅니다. `반 인원`을 정해 두면 그 인원 기준으로 나옵니다.
5. 작품마다 `점수와 코멘트`(박자 이해, 창의성, 표현 각 1~5점, 코멘트 300자)를 저장하면 학생이 창작 페이지의 `피드백 보기`로 확인합니다.
6. `엑셀(CSV)로 내려받기`로 제출 현황과 점수, 코멘트를 한 파일로 받아 엑셀에서 엽니다. 안 낸 번호도 `안 냄`으로 들어갑니다.
7. 수업이 끝나면 `반 닫기`로 그 반 전체의 저장을 막고, 다음에 쓸 때 `반 열기` 또는 `QR 새로 만들기`를 합니다.
8. 반 카드에서 `모둠 수`만 적고 `모둠 만들기`를 누르면 반 인원(작품 보기에서 정해 둔 인원, 없으면 30명)을 그 수만큼의 모둠으로 무작위 편성합니다. `번호순으로`는 1번부터 차례로 나눕니다. 편성 결과는 `모둠 보기`에서 확인하고 복사할 수 있어요. 학생은 창작 페이지에서 `모둠`을 고르고 내 번호를 적은 뒤 `내 모둠 찾기`를 누르면 자기 모둠 번호와 같은 모둠 친구 번호가 나옵니다.
9. 특정 모둠만 막고 싶으면 반 카드에서 모둠 번호를 적고 `모둠 닫기`를 누릅니다. 닫힌 모둠은 `모둠 3 ✕`처럼 표시되고, 눌러서 다시 열 수 있어요. 이미 낸 작품은 그대로 남습니다.

학생은 이름 없이 반과 번호만 적습니다. 번호로 본인 확인은 되지 않으니, 필요하면 수업 중 선생님이 화면에서 확인하세요.

## 저장되는 것

- QR 없이 들어온 경우: 만든 리듬은 학생의 브라우저(localStorage)에만 저장돼요.
- QR로 들어와 `임시 저장` 또는 `제출하기`를 누른 경우: Firebase에 저장돼요. 제출한 작품은 선생님 화면에서 바로 보이고, 임시 저장은 `작성 중 포함 전체`에서 볼 수 있어요. 개인은 같은 기기, 반, 번호, 박자가 한 작품을 덮어쓰고, 모둠은 같은 반, 모둠 번호, 박자의 작품 하나를 모둠 친구들이 함께 덮어씁니다.

## 참고

- 소리는 브라우저가 만들어 내는 대용 소리라 실제 카혼 소리와 다릅니다.
- 연주 페이지의 리듬꼴은 예시이므로 수업 영상에 맞춰 고쳐 쓰세요.
- 글꼴(Jua, Noto Sans KR)은 인터넷 연결이 있을 때 구글 폰트에서 불러옵니다.
- Firebase 기능은 GitHub Pages 같은 인터넷 주소에서 동작해요. `index.html`을 더블클릭해 연 화면에서는 로그인과 저장이 되지 않습니다.
- 로그인 오류가 `api-key-not-valid`면 `firebase.js`의 `apiKey`를 Firebase 콘솔의 값과 다시 비교해 보세요.
