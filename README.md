# 즐거운 카혼수업

카혼의 **이론**, **연주**, **창작**을 배우는 수업용 웹앱입니다. 설치나 빌드 없이 파일만 올리면 동작하는 정적 사이트예요.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 뼈대 |
| `style.css` | 디자인(밝은/어두운 화면 모두 지원) |
| `app.js` | 메뉴, 이론 내용, 연주 리듬, 두드리는 카혼, 창작 기능 |

## 메뉴

- **이론**: 카혼의 유래, 연주 자세, 구조
- **연주**: 기초(기호와 손 표시, 4비트), 기본(8비트, 16비트), 응용(8개 리듬)
- **창작**: 4·8·16비트를 고르고 필인 유무를 정한 뒤 아이콘을 끌어다 놓아 리듬 만들기

모든 화면 오른쪽 위의 `바로가기` 버튼으로 메뉴 트리를 열 수 있어요.

## 기호

| 모양 | 이름 | 설명 |
| --- | --- | --- |
| 빨간 동그라미 | 베이스 (Bass) | 낮은 소리 |
| 파란 네모 | 셰이프 (Shape) | 세게 치기 |
| 노란 다이아몬드 | 터치 (Touch) | 양쪽 가장자리를 약하게 치기 |

기호 안의 `R`은 오른손, `L`은 왼손입니다. 박 세기는 `1 n 2 n 3 n 4 n`이고 n은 박과 박 사이입니다.

## 내 컴퓨터에서 보기

`index.html`을 더블클릭하면 브라우저에서 열려요. 소리가 나려면 화면을 한 번 누르거나 버튼을 눌러야 합니다.

## GitHub에 올리기

### 웹에서 올리기

1. GitHub에서 새 저장소(Repository)를 만듭니다. 이름 예: `cajon-class`
2. 저장소 화면에서 **Add file → Upload files**를 누릅니다.
3. 이 폴더 안의 `index.html`, `style.css`, `app.js`, `README.md`를 끌어다 놓고 **Commit changes**를 누릅니다.

### 명령어로 올리기

```bash
cd cajon-class
git init
git add .
git commit -m "즐거운 카혼수업 첫 버전"
git branch -M main
git remote add origin https://github.com/내아이디/cajon-class.git
git push -u origin main
```

### 인터넷 주소 만들기 (GitHub Pages)

1. 저장소의 **Settings → Pages**로 갑니다.
2. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 정하고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://내아이디.github.io/cajon-class/` 주소로 학생들이 접속할 수 있어요.

## 내용 고치기

### 수업 영상 넣기

`app.js` 맨 위쪽의 `VID`에 페이지별 유튜브 영상 ID를 넣으면 그 페이지에 영상이 나옵니다.
영상 주소가 `https://youtu.be/AbCdEfGhIjK`라면 ID는 `AbCdEfGhIjK`입니다.

```js
const VID={o:'AbCdEfGhIjK', po:'', st:'', f1:'', f4:'', m8:'', m16:'', a1:'', ...};
```

| ID | 페이지 |
| --- | --- |
| `o`, `po`, `st` | 이론: 유래, 자세, 구조 |
| `f1`, `f4` | 기초: 기호와 손, 4비트 |
| `m8`, `m16` | 기본: 8비트, 16비트 |
| `a1` ~ `a8` | 응용 1~8 |

### 리듬 바꾸기

`app.js`의 `TREE`에서 각 페이지의 `p:'...'` 문자열이 리듬입니다.

- 칸은 띄어쓰기로 나눕니다.
- 첫 글자는 소리: `B` 베이스, `H` 셰이프, `T` 터치
- 둘째 글자는 손: `R` 오른손, `L` 왼손 (예: `BR`, `HL`, `TL`)
- `.`은 쉼입니다.

```js
{t:'1마디',p:'BR BL HR TL BR BL HR TL'}   // 8비트: 칸이 8개
```

4비트는 4칸, 8비트는 8칸, 16비트는 16칸으로 맞춰 주세요.

### 사진 넣기

이론 페이지의 `사진 자리` 그림 대신 실제 사진을 쓰려면 사진 파일을 같은 폴더에 올리고, `app.js`의 `box(...)` 부분을 `<img src="사진이름.jpg" alt="설명">`으로 바꾸면 됩니다.

## 저장되는 것

창작에서 만든 리듬은 학생의 브라우저(localStorage)에 저장돼요. 기기마다 따로 저장되고, 다른 기기나 선생님 화면에서는 보이지 않습니다.

## 참고

- 소리는 브라우저가 만들어 내는 대용 소리라 실제 카혼 소리와 다릅니다.
- 연주 페이지의 리듬꼴은 예시이므로 수업 영상에 맞춰 고쳐 쓰세요.
- 글꼴(Jua, Noto Sans KR)은 인터넷 연결이 있을 때 구글 폰트에서 불러옵니다.
